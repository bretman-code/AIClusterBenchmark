# iPhone preview

Минимальная iOS-версия: встроенная SmolLM2-135M Q4_K_M, CPU-тест генерации
с теми же настройками, что Android (2 потока, контекст 256, до 32 токенов), экспорт JSON.
Сеть и распределённый запуск в первую версию не входят.

Сборка: GitHub Actions Build iPhone IPA на macOS с Xcode.
Исходники llama.cpp и модель скачиваются с проверкой SHA-256; лицензии входят в приложение.
Поддержка: iOS 16+, arm64. Первым проверяется iPhone 15 Pro.

IPA публикуется в prerelease ios-preview. Он подписан только технической ad-hoc
подписью без provisioning profile и не устанавливается прямым открытием ссылки.
Для установки с Windows нужно переподписать и установить IPA через Sideloadly
с собственной учётной записью Apple. Данные Apple вводятся пользователем локально;
сборка в GitHub не требует Apple ID, пароля или сертификата.
Факт успешной сборки не доказывает запуск на конкретном iPhone.
