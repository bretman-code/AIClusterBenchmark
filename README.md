# AI Cluster Benchmark v0.3

Android-приложение для сравнения телефонов: CPU, копирование памяти и реальная генерация токенов нейросетью через llama.cpp. Android 8.1+, ARM 32/64 бит.

## Установка

Скачайте APK из [Releases](https://github.com/bretman-code/AIClusterBenchmark/releases).
Версия 0.3 устанавливается поверх 0.1/0.2 при совпадении подписи.

На главном экране доступны быстрый тест CPU/RAM, отдельный LLM-тест и проверка связи по Wi-Fi.
Тёмный интерфейс с карточками, крупными кнопками и прокруткой.
Результаты обоих типов сохраняются в JSON через системный выбор папки.

Для LLM просто откройте экран теста: небольшая модель SmolLM2-135M Q4_K_M
включена в APK и автоматически подготовится без интернета. Затем запустите тест.
Инструкции: [LLM-тест](LLM-TEST-RU.md), [сравнение CPU/RAM](TESTING-RU.md).
Связь между телефонами: [Wi-Fi тест](LAN-TEST-RU.md).

## Сборка

JDK 17, Gradle 8.9, Android SDK 35, Build Tools 35.0.0,
NDK 27.2.12479018, CMake 3.22.1. Минимальный API 27, целевой API 34.
Откройте проект в Android Studio или запустите GitHub Actions Build Android APK.
Команда: `gradle --no-daemon assembleDebug lintDebug testDebugUnitTest`.
При первой сборке CMake скачивает llama.cpp b5046 с проверкой SHA-256.
Перед сборкой задача prepareBundledModel скачивает GGUF (если файл отсутствует)
и проверяет SHA-256. Веса находятся в app/src/main/assets/models и исключены из Git;
архив исходников содержит рецепт получения точного файла. В APK модель включена.
Лицензии llama.cpp и модели, а также сведения об авторах включены в APK.

## Проверка

Версия 0.1 запущена пользователем на телефоне с Android 13 и 32-битной средой.
Версия 0.2 успешно выполнила реальную генерацию на 32-битном телефоне пользователя:
32 токена, около 7.36 токенов/с, SmolLM2-135M Q4_K_M.
Версия 0.3 сохраняет тот же нативный движок для armeabi-v7a и arm64-v8a.
Новый сетевой протокол проверяется JVM-тестами; Android-автопоиск и передача
между реальными телефонами ещё требуют проверки.
Скорость нейросети не выводится из синтетических баллов.

## Ограничения

CPU-тест однопоточный. RAM-тест отражает копирование массивов и влияние кэша,
а не чистую пропускную способность DRAM. Короткий тест повторяемости
не является тестом температуры или длительного троттлинга.
LLM-тест: первый проход, 2 потока, контекст 256, не более 32 токенов.
Сравнивайте только одинаковые SHA-256 модели и настройки.
Большие модели могут исчерпать память; начните с предлагаемой SmolLM2-135M.
Wi-Fi поиск и тест связи реализованы. Распределённая генерация и длительная нагрузка пока не реализованы.
